# Completed Phases

Empty for now.

When a phase in `../pending/` has every acceptance criterion verified, append a completion
record to it and move the file here:

```markdown
---
## Completion record
- Completed: YYYY-MM-DD
- Verified by: <how — which test, which manual check>
- Deviations from plan: <what you built differently, and why>
- Follow-ups created: <new files added to pending/, if any>
```

The **deviations** line is the one that matters. In six months the plan will not match the
code, and this is the only place that will tell you why.
